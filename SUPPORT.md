# Support

Read [README.md](README.md) and the [setup guides](docs/setup/). For a reproducible
software problem use the bug template; for a feature proposal use the feature template.
Include OS/tool versions, the exact command, expected/actual behavior and sanitized
logs. Replace private paths, hostnames, account IDs, API keys and shop content first.

Do not attach `.env.local`, browser profiles/cookies, private CSVs, database dumps or
unredacted screenshots. “Unverified” is a diagnostic state, not clearance. Government
account approval and provider billing are controlled by those organizations.

For private support/accessibility/conduct inquiries: contact@iscalelabs.com.
Community help is best-effort; no response-time or paid-support promise is implied.
Report vulnerabilities using [SECURITY.md](SECURITY.md), not public issues.
